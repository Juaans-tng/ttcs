[Thực hành] Danh sách trong CSS

Luyện tập sử dụng các thuộc tính CSS để định kiểu, đổi vị trí, sử dụng hình ảnh và phối màu cho danh sách HTML.

2. Danh sách không thứ tự (Dấu vuông)

list-style-type: square;

Sử dụng thẻ <ul> và thuộc tính list-style-type để chuyển dấu đầu dòng thành hình vuông.

  • CSS
  • JavaScript
  • Git

3. Danh sách có thứ tự (Số La Mã in hoa)

list-style-type: upper-roman;

Sử dụng thẻ <ol> và thuộc tính list-style-type để đánh số các bước bằng chữ số La Mã.

  1. Học HTML
  2. Học CSS
  3. Học JavaScript
  4. Học Git

4. Sử dụng hình ảnh làm dấu đánh dấu

list-style-image: url('bullet.png');

Sử dụng thuộc tính list-style-image kết hợp với hàm url() để đặt biểu tượng hình ảnh làm dấu đầu dòng.

  • Visual Studio Code
  • Google Chrome
  • GitHub
  • Git

5. Thay đổi vị trí dấu đánh dấu

list-style-position: outside | inside;

So sánh vị trí dấu đánh dấu nằm bên ngoài lề nội dung (outside) và nằm bên trong khối nội dung (inside).

Vị trí Outside (Mặc định)

  • Visual Studio Code
  • Google Chrome
  • GitHub

Vị trí Inside (Bên trong hộp)

  • Visual Studio Code
  • Google Chrome
  • GitHub

6. Thuộc tính rút gọn list-style

list-style: square inside url('bullet.png');

Thiết lập đồng thời kiểu đánh dấu (type), vị trí (position) và hình ảnh (image) chỉ với một dòng CSS ngắn gọn.

  • Cú pháp rút gọn giúp code ngắn gọn và dễ bảo trì
  • Kết hợp đồng thời kiểu dấu dự phòng và hình ảnh
  • Điều chỉnh vị trí hiển thị vào bên trong khối nội dung

7. Tạo kiểu danh sách với màu sắc & khoảng cách

background-color, color, padding, margin

Định kiểu danh sách các ngôn ngữ lập trình với màu nền tối, màu chữ cyan và khoảng cách đệm hài hòa.

  • HTML

8. Bài tập tổng hợp: Lộ trình học lập trình Web

list-style: decimal inside;

Kết hợp cấu trúc danh sách, kiểu đánh dấu, màu nền hiện đại, khoảng cách padding/margin và hiệu ứng hover.
