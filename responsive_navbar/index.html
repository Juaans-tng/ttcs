Bài 1: Thực hành Responsive Navbar

Thanh Điều Hướng Đáp Ứng Đa Thiết Bị

Thực hành áp dụng Flexbox, Media Queries trong CSS và JavaScript để xử lý mở/đóng menu trên thiết bị di động.

🖥️

Giao diện Desktop (> 768px)

Các mục điều hướng hiển thị thành hàng ngang (Flexbox row). Biểu tượng menu hamburger (☰) tự động ẩn đi.

📱

Giao diện Mobile (≤ 768px)

Danh sách menu ẩn đi, biểu tượng (☰) xuất hiện. Bấm vào biểu tượng để kích hoạt hiển thị menu dọc (toggle class active).

⚡

Tương tác linh hoạt

Hỗ trợ thao tác chạm, bấm biểu tượng hamburger, tự động đóng khi chọn mục menu trên màn hình di động.

💡 Hướng dẫn kiểm tra:

  1. Mở công cụ kiểm tra của trình duyệt bằng cách nhấn F12 (hoặc chuột phải chọn Inspect).
  2. Bật chế độ Toggle Device Toolbar (Ctrl + Shift + M) để thu nhỏ kích thước màn hình xuống dưới 768px.
  3. Quan sát thanh điều hướng chuyển thành icon ☰ và nhấp vào để kiểm tra menu trượt mở mượt mà.
