CSS | Thuộc tính grid-column-start

Xác định đường kẻ cột (column line) nơi Grid Item bắt đầu hiển thị

📐 Sơ đồ hệ trục đường kẻ cột (Column Lines)

Với Grid có 4 cột, sẽ có 5 đường kẻ cột được đánh số thứ tự từ 1 đến 5:

Đường kẻ 1
Cột 1
Đường kẻ 2
Cột 2
Đường kẻ 3
Cột 3
Đường kẻ 4
Cột 4
Đường kẻ 5
grid-column-start: auto | span n | column-line;

1. Giá trị auto (Mặc định)

grid-column-start: auto;

Item được đặt theo luồng sắp xếp thông thường của Grid (bắt đầu tự động tại ô trống tiếp theo).

1 (auto)
2
3
.grid-container {
    display: grid;
    grid-template-columns: 100px 100px 100px;
    gap: 10px;
}
.item1 {
    grid-column-start: auto;
}

2. Giá trị span n (Kéo dài n cột)

grid-column-start: span 2;

Chỉ định Grid Item kéo dài qua số lượng cột là n (trong ví dụ là span 2, Item 1 chiếm 2 cột).

Item 1 (span 2)
Item 2
Item 3
Item 4
.grid-container {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 10px;
}
.item1 {
    grid-column-start: span 2;
}

3. Giá trị column-line (Đường kẻ cụ thể)

grid-column-start: 2;

Chỉ định Item bắt đầu từ đường kẻ cột số 2 (do đó Cột 1 phía trước để trống).

Item 1 (start: 2)
Item 2
Item 3
Item 4
.grid-container {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 10px;
}
.item1 {
    grid-column-start: 2;
}
