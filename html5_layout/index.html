Tìm hiểu các thẻ ngữ nghĩa HTML5 Semantic Elements

Tác giả: Ban Chuyên Môn CodeGym • Ngày đăng: 19/10/2026 • Chuyên mục: Frontend Development

Trước phiên bản HTML5, các nhà phát triển web thường sử dụng các thẻ <div> với thuộc tính id hoặc class để chia vùng trang web (ví dụ: <div id="header">, <div id="nav">, <div id="footer">).

Với sự ra đời của HTML5, các thẻ ngữ nghĩa (Semantic Elements) như <header>, <nav>, <section>, <article>, <aside>, và <footer> giúp cấu trúc website trở nên sáng sủa hơn, tối ưu cho các công cụ tìm kiếm (SEO) và hỗ trợ các thiết bị trợ thính, đọc màn hình.

So sánh bố cục bằng Float vs Flexbox trong thiết kế Web

Tác giả: Nguyễn Văn A • Ngày đăng: 18/10/2026 • Chuyên mục: CSS3 Kỹ Thuật

Thuộc tính float ban đầu được thiết kế để đẩy hình ảnh sang bên trái hoặc phải nhằm cho văn bản bao quanh. Khi dùng float để chia cột bố cục, ta luôn phải dùng clear (hoặc Clearfix) để tránh hiện tượng sụp đổ chiều cao của container cha.

Ngày nay, các kỹ thuật hiện đại như CSS Flexbox và CSS Grid đã trở thành tiêu chuẩn vượt trội, giúp việc dàn layout đa chiều và Responsive trên mọi kích thước màn hình trở nên đơn giản, trực quan hơn rất nhiều.
