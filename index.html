[Thực hành] Sử dụng Box Model 1

Minh họa cách tính kích thước tổng thể của một phần tử trong mô hình hộp (Box Model).

Content demo box

📐 Chi tiết tính toán kích thước Box Model

Tổng chiều rộng của phần tử <div> trên được tính bằng công thức:

Thành phần Box Model Giá trị thiết lập Kích thước đóng góp vào chiều rộng
Content Width (Chiều rộng nội dung) width: 200px; 200px
Padding (Đệm trái + phải) padding: 35px; 35px (trái) + 35px (phải) = 70px
Border (Viền trái + phải) border: 20px dashed indianred; 20px (trái) + 20px (phải) = 40px
Margin (Lề ngoài trái + phải) margin: 25px; 25px (trái) + 25px (phải) = 50px
TỔNG CHIỀU RỘNG (Total Width) 200 + 70 + 40 + 50 = 360px

💡 Công thức: Total Width = width + (padding-left + padding-right) + (border-left + border-right) + (margin-left + margin-right) = 360px
