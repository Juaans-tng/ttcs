# GitProject 🚀

Dự án thực hành các thao tác cơ bản với **Git và GitHub** theo chuẩn quy trình bài tập CodeGym.

## 📌 Nội Dung Dự Án
- **Khởi tạo và cấu hình Git**: `git init`, `git config`
- **Quản lý phiên bản tập tin**: `git add README.md`, `git commit -m "Add README.md"`
- **Quản lý mã nguồn dự án**: Thư mục `source/` chứa các trang HTML:
  - [`source/index.html`](./source/index.html): Trang chủ dự án Index Page
  - [`source/news.html`](./source/news.html): Trang tin tức News Page
- **Đẩy mã nguồn lên GitHub**: `git push origin main`

## 🛠️ Công Nghệ Sử Dụng
- HTML5, CSS3
- Git CLI & GitHub
