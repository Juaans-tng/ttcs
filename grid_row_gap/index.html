CSS | Thuộc tính grid-row-gap

Xác định kích thước khoảng cách (gap) giữa các hàng trong CSS Grid Layout

📖 Cú pháp & Giá trị của grid-row-gap

grid-row-gap: length | percentage | global-values;

💡 Lưu ý hiện đại: Trong CSS hiện đại (Grid Specification mới), thuộc tính row-gap được khuyến khích sử dụng thay cho tiền tố cũ grid-row-gap (cả hai đều hoạt động tương đương nhau).

1. Giá trị độ dài cố định: grid-row-gap: 20px;

grid-row-gap: 20px;

Khoảng cách giữa các hàng trong Grid được thiết lập cố định là 20px.

.grid-container {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    grid-row-gap: 20px;
}
.grid-container div {
    background-color: lightblue;
    padding: 20px;
    text-align: center;
}

2. Giá trị phần trăm: grid-row-gap: 5%;

grid-row-gap: 5%; (height: 400px)

Khoảng cách giữa các hàng được tính bằng 5% theo chiều cao của container (400px * 5% = 20px).

Ô 1
Ô 2
Ô 3
Ô 4
.grid-container {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    grid-row-gap: 5%;
    height: 400px;
}
.grid-container div {
    background-color: lightgreen;
    padding: 20px;
    text-align: center;
}

3. Giá trị toàn cục (Global Values)

initial | inherit | unset
  • initial: Đặt thuộc tính về giá trị mặc định ban đầu (0px - không có khoảng cách hàng).
  • inherit: Kế thừa giá trị khoảng cách hàng từ phần tử cha bao bọc.
  • unset: Nếu có thể kế thừa thì kế thừa, nếu không thì lấy giá trị khởi tạo.
